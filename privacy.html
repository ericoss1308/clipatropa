Clipatropa

Política de Privacidade

Última atualização: 10 de agosto de 2026

O Clipatropa é uma extensão para Google Chrome que detecta e baixa vídeos reproduzidos em páginas da web. Esta política explica como a extensão trata os dados do usuário.

Resumo: o Clipatropa não coleta, armazena, transmite ou compartilha nenhum dado pessoal do usuário. Todo o processamento acontece localmente, no próprio navegador.

Coleta de dados

O Clipatropa não coleta, armazena, transmite ou compartilha nenhum dado pessoal do usuário com servidores externos. A extensão não possui backend, servidor próprio ou serviço de análise (analytics).

Como a extensão funciona

Todo o processamento acontece localmente, no navegador do próprio usuário:

  • A detecção de vídeos (arquivos diretos, streams HLS e DASH) é feita observando o tráfego de rede e o conteúdo da página, apenas na aba em que o usuário está utilizando a extensão.
  • O download dos arquivos de vídeo/áudio é salvo diretamente no dispositivo do usuário, via API nativa do Chrome (chrome.downloads).
  • A conversão de áudio (MP3/WAV) é feita inteiramente no navegador, usando a Web Audio API e bibliotecas incluídas no próprio pacote da extensão — nenhum arquivo é enviado para fora do dispositivo do usuário.

Armazenamento local

A extensão pode usar a API chrome.storage apenas para guardar preferências do usuário (como formato ou qualidade selecionados anteriormente) localmente no navegador. Esses dados não saem do dispositivo do usuário e não são acessíveis a terceiros.

Permissões

A extensão solicita acesso amplo a sites (host permissions) exclusivamente para poder detectar vídeos em qualquer página visitada pelo usuário. Esse acesso é usado somente para identificar conteúdo de mídia — nenhuma informação de navegação é registrada, armazenada ou compartilhada.

Compartilhamento com terceiros

O Clipatropa não vende, aluga ou compartilha dados de usuários com terceiros, sob nenhuma circunstância.

Alterações nesta política

Esta política pode ser atualizada eventualmente. Alterações significativas serão refletidas na data no topo desta página.
